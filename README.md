# 🎨 Random Color Generator

A simple web project that generates a random color with each click.  
It also updates the background color and shows the HEX color code.

---

## 🚀 Features
- Generates a random HEX color  
- Changes the background instantly  
- Displays the color code  
- Clean and minimal UI  
- Beginner-friendly JavaScript project
